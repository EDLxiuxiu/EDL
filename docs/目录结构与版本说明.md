## 启动与历史工具

日常双击 `00_启动系统.bat`，连接已有主库并自动打开网页。维护仍用根目录 `manage.py`。历史工具改用模块方式，从项目根目录运行，例如：

```powershell
.\.venv\Scripts\python.exe -B -m tools.legacy.query_candidate --help
.\.venv\Scripts\python.exe -B -m tools.legacy.report_admission_run --help
```

诊断工具同理用 `-m tools.diagnostics.模块名`。这些历史工具继续服务对应历史库，不是日常系统入口；有写入作用的命令应按原实验版本与说明复现。

## 历史材料的版本边界

设计报告 Markdown 和 Word 保留 `1424f2d` 验收版，配合本说明阅读其中旧路径。原 Word 的排版及验收摘要不因目录调整改写。部署、使用和交付清单已更新为当前目录。

`experiments/` 中既有报告、结果和源码快照不迁移、不改写 SHA。整理前完整主系统可从 Git `1424f2d` 查阅；早期独立实验按 Git `30ebf707c2a7180d3ede588812458da8e4d11ff5` 或当轮 `source_snapshot.zip` 复现。历史报告中的根目录路径属于当轮版本，不能直接作为当前布局命令。

本次整理复用已有应用账号、密码和三个数据库，不新建数据库，也不重导入或重跑 15 万人。当前源码摘要与历史记录不同是版本变化，不能修改旧摘要来伪装一致。
